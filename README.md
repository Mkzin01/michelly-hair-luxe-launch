Exportação (Muito Importante)

Quando o projeto estiver finalizado:

Gere também uma versão pronta para hospedagem.

Quero receber um arquivo ZIP contendo todo o projeto completo, semelhante ao exportado pelo Claude.

O ZIP deve conter uma estrutura organizada, por exemplo:

michelly-hair-landing/
│
├── index.html
├── assets/
├── css/
├── js/
├── fonts/
├── favicon/
└── demais arquivos necessários

Ou, caso utilize React/Vite (ou outro framework moderno), exporte a versão compilada (build de produção) pronta para hospedagem, com todos os arquivos estáticos necessários (index.html, pasta assets, CSS e JavaScript gerados).

O projeto deve funcionar diretamente ao ser enviado para serviços como:

Netlify
Vercel
Cloudflare Pages
Hostinger
GitHub Pages
Firebase Hosting

Não quero apenas o código-fonte do projeto. Quero também uma versão pronta para publicação, compactada em um único arquivo .zip, mantendo todas as animações, transições, efeitos visuais e o mesmo design premium do site. O resultado deve ser idêntico ao projeto visual, apenas com uma estrutura de exportação compatível com plataformas de hospedagem.
